# Installer artwork

Original geometric package illustration generated by `scripts/generate-installer-art.ps1` using Windows System.Drawing. No third-party image assets or rendered text.

- welcome.bmp: 260×470, 24-bit RGB; displayed at 130×235 installer units.
- banner.bmp: 780×104, 24-bit RGB; displayed at 390×52 installer units.
- *-preview.png: visual inspection copies; not embedded in MSI.
- app-icon.png: transparent 256×256 cube icon for the application.
- app-icon.ico: 16/24/32/48/64/128/256 pixel Windows icon frames.

The installer and application icons share `scripts/draw-package.ps1`, preserving the same original cube geometry and colors. Regenerate application icons with `scripts/generate-app-icon.ps1`; it also updates the Tauri icon files and the builder UI copy.

Regenerate from the repository root with PowerShell:

```powershell
./scripts/generate-installer-art.ps1
```
