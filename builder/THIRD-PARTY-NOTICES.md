# Express MSI Builder GUI dependencies

The GUI uses Tauri 2 (Apache-2.0 OR MIT), serde and serde_json (MIT OR Apache-2.0), and rfd (MIT). The native engine uses xml-rs (MIT). Versions are locked in Cargo.lock; dependency license expressions and upstream repositories are recorded in third-party-dependencies.json.

The portable development distribution generated by scripts/build-builder.ps1 includes dependency license/notice files under licenses/ and an accompanying dependencies.json. The inventory includes build-time dependencies as well as runtime dependencies. Windows and WebView2 remain platform prerequisites.
