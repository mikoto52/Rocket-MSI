# Rocket MSI 설치 UI

2026-10-19 기준. 현재는 Windows Installer의 기본 대화상자로 구성한 마법사 방식이다. Quick MSI 첫 단위는 별도 화면 방식이며 [Quick MSI 안내](quick-msi.md)를 따른다. 이 문서는 기존 마법사 방식의 명세다.

## 화면 흐름

- 신규 설치: 환영 → 사용권 계약(지정한 경우) → 설치 폴더 선택 → 설치 준비 완료 → 진행 → 완료.
- 유지보수: 설치 복구 및 제거 → 복구 또는 제거 확인 → 진행 → 완료.
- 취소: 취소 확인에서 예를 선택 → 중단 화면. 아니요·Esc·확인 창 닫기는 작업을 계속한다.
- 실패: 실패 화면. 실행 중 취소와 실패의 실제 롤백은 MSI 엔진의 실행 상태에 따른다.

환영·완료·중단 화면에는 왼쪽 이미지를 표시한다. 나머지 주요 페이지에는 상단 배너와 작은 굵은 제목, 안내 문구를 표시한다. 사용권 계약의 스크롤 본문에는 테두리를 표시하고, 동의 전에는 다음 버튼을 비활성화한다.

설치 폴더는 직접 입력하거나 찾아보기로 선택한다. 경로 변경을 허용하지 않은 프로젝트에서는 두 입력 수단을 비활성화한다.

## 유지보수

복구·제거는 라디오 버튼으로 선택한다. 각 항목에는 공구·휴지통 아이콘과 설명을 표시한다. 별도 Text 컨트롤은 RadioButtonGroup 영역과 겹치지 않도록 오른쪽 열에 배치한다. 그룹이 겹친 컨트롤을 가리는 문제와 지나치게 좁은 라디오 제목이 잘리는 문제를 반영한 구성이다.

초기 선택값은 없으며 선택 전에는 실행 버튼을 비활성화한다. 실행 버튼은 작업별 확인 페이지로 이동할 뿐, 복구나 제거를 시작하지 않는다. 확인 페이지의 복구·제거 버튼에서 MSI 작업 속성을 설정하고 실행한다. 뒤로 버튼은 선택 화면으로 돌아간다.

진행 화면의 제목·본문과 완료 본문의 작업명은 설치·복구·제거에 따라 바뀐다. 상태 텍스트와 진행 막대는 MSI 이벤트에 연결한다. 설치 후 실행 옵션은 기존 정책대로 신규 설치 완료에서만 제공한다.

## 버튼과 취소 확인

공통 버튼 표기는 `< 뒤로(&B)`, `다음(&N) >`, `설치(&I)`, `실행(&E)`, `복구(&P)`, `제거(&R)`, `취소(&C)`, `마침(&F)`이다. Windows는 `&`를 단축키 표시로 처리한다. 실패 화면은 닫기를 사용한다.

취소 확인은 `[ProductName] [작업명]를 정말로 취소하시겠습니까?`를 표시한다. 복구·제거 선택 전 작업명은 유지보수이며, 선택 후에는 선택한 작업을 표시한다. 예는 취소하고 아니요는 원래 화면으로 돌아간다. 폴더 찾아보기의 취소는 폴더 선택만 취소한다.

## 브랜딩과 호환성

기본 BrandingText는 Rocket MSI다. 사용자가 지정한 값은 하단뿐 아니라 마법사 이름을 포함한 환영·진행·완료·중단 문구에 적용한다. MSI에는 `[BrandingText]` 참조로 저장하며 프로젝트 XML에서는 `<BrandingText>`로 설정한다.

하단 위치는 X=2, Y=234, Height=12다. Width는 빌드 시 맑은 고딕 글자 폭을 측정하고 배율·글꼴 차이를 고려한 여유를 더해 계산한다. 최소 1, 최대 386이며 매우 긴 문구의 완전한 표시를 보장하지 않는다. 실행 시 속성 값을 바꾸더라도 너비를 다시 측정하지는 않는다. 전체 구분선 위에 불투명 텍스트 배경을 덮는 방식을 유지한다.

이전 기본값 Express MSI Builder와 InstallEmbly는 프로젝트를 읽을 때 Rocket MSI로 변환한다. 다른 사용자 지정 문구는 보존한다. `.embproj`, XML 루트 `ExpressMsiBuilderProject`, 기존 설치 정보·시험용 경로는 호환성을 위해 유지한다. 저장소 주소도 현재 `mikoto52/InstallEmbly`다.

## 검증 범위

자동 검사는 실제 MSI 생성과 세션 열기, 화면 이동, 확인 후 작업 실행, 취소 연결, 약관 동의 조건, 사용자 지정 브랜딩, 라디오 그룹과 설명의 비중첩, 글자 폭에 따른 너비 계산을 포함한다. 설치를 자동 실행하지 않는다.

사용자 화면 확인 과정에서 설명 가림·라디오 제목 잘림·하단 브랜딩 말줄임을 수정했다. 최신 너비 보정본은 실제 표시 재확인이 필요하다. 배율별 표시와 설치·복구·제거 전체 흐름은 시험 환경에서 수동 확인한다. `dist/ui-text-demo`의 로컬 시험 결과물은 Git에 포함하지 않으며 배포 릴리스가 아니다.
