# Rocket MSI 0.3.0 🚀

## 새 기능

- **ARM64 MSI 생성**: GUI와 `.embproj`에서 ARM64를 선택할 수 있습니다. ARM64 실행 도우미와 Quick MSI DLL을 포함하며 64비트 파일·레지스트리·바로가기 경로를 지원합니다.
- **MSI 전자서명**: PFX/P12 파일 또는 Windows 개인 인증서 저장소에서 인증서를 선택하여 SHA-256으로 서명합니다.
- **타임스탬프와 검증**: RFC 3161 타임스탬프 서버를 지정할 수 있으며 서명 후 Windows 신뢰 체인을 검증합니다. 서명이나 검증이 실패하면 최종 MSI·외부 CAB를 내보내지 않습니다.
- **CLI 서명 검증**: `verify-signature <package.msi>` 명령을 추가했습니다.

## 배포 파일

- `Rocket-MSI-0.3.0-windows-x64.zip`: GUI·CLI, MIT 라이선스, 외부 의존성 고지를 포함합니다. ZIP 안의 파일을 같은 폴더에 풀어 사용하세요.
- `SHA256SUMS.txt`: 배포 ZIP의 SHA-256 해시입니다.

빌더는 Windows x64에서 실행하며 x86/x64/ARM64 MSI를 생성합니다. GUI는 WebView2, 전자서명 기능은 Windows SDK SignTool이 필요합니다. ARM64 대상 EXE/DLL은 별도로 준비해야 합니다. Quick MSI의 사용권 계약 표시는 아직 지원하지 않습니다.

PFX 암호는 프로젝트에 저장하지 않습니다. GUI에서는 빌드할 때 입력하고 CLI에서는 `ROCKET_MSI_PFX_PASSWORD` 환경 변수를 사용합니다. 로컬 컴퓨터 인증서는 개인 키 사용 권한이 필요합니다.

## 검증 범위

엔진 30개와 GUI 4개, 총 34개 테스트 및 엔진·GUI 정적 검사를 통과했습니다.

- 세 아키텍처의 MSI 생성·테이블·내장 Quick MSI DLL 형식 및 기존 기능 회귀 검사
- 임시 PFX와 인증서 저장소를 사용한 실제 MSI 서명·RFC 3161 타임스탬프, 신뢰되지 않은 인증서 거부 및 실패 시 출력 차단
- ARM64 장치의 실제 설치·복구·제거와 실제 발급 인증서에 대한 신뢰 체인 검증은 별도 확인이 필요합니다.
